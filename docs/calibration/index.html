How It Works

ELO ratings are maintained per (team, age-group) pair. Before each game, each team has a rating; the expected win probability for the home side is:

P(home wins) = 1 / (1 + 10(ELO_away − ELO_home) / 200)

K-factor is 32. Ratings regress 40% toward 1500 between seasons to account for roster turnover. At the start of each season, win probabilities are additionally pulled 80% toward 50% (pure coin flip) and this season-start regression fades linearly to 0% once teams have averaged 6 games played — reflecting that early-season ELO ratings are less reliable. The season simulation uses these ratings plus a fixed 22% draw probability to run 400 Monte Carlo trials per team.
